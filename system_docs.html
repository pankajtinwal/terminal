🎯 What This System Does

This platform is a fully serverless, zero-cost financial analytics dashboard for 132 hand-picked Indian small- and mid-cap stocks. Unlike Nifty50 (market-cap weighted), this system synthesizes custom equal-weighted indices — one master index and 13 sector sub-indices — using a base of 1000 on the first day of data.

The system answers a core question: "If you had invested equally in all stocks within a sector, how would that portfolio look as a single chart today?"

Everything is updated twice daily, deployed to the edge via Cloudflare Pages, and rendered in the browser — no backend server required, no database, no cost.

💡 Core Design Philosophy

JAMstack architecture — Python computes data offline, commits static JSON to GitHub, and the HTML/JS frontend fetches it directly. No runtime server. No API keys exposed. No database. The "backend" is just a scheduled GitHub Action + Python script.

🔑 Key Design Decisions

• Delta cache — only fetches new trading days each run
• Equal-weighting — no stock dominates by market cap
• Base 1000 — intuitive, like Nifty. Easy % gain from base
• Vendor-first assets — local JS libraries for offline resilience

Data Ingestion Layer
How we pull and cache 132 stocks from Yahoo Finance
🔄 Delta Caching Strategy

Rather than re-downloading full history every run, the pipeline uses a delta cache approach:

1. On first run → download 1 year of daily OHLCV data for every stock and save to data/history.json
2. On subsequent runs → check the last date in cache per ticker, fetch only new trading days
3. Merge new rows into existing cache and re-save

This reduces typical update time from ~15 minutes down to under 2 minutes.

⚠️ Anti-Ban Rate Limiting

Yahoo Finance throttles aggressive scrapers. The ingestion loop adds a random 1.5–3.0 second delay between each ticker fetch to avoid 429 errors.

time.sleep(random.uniform(1.5, 3.0))
🔧 Ticker Symbol Overrides

Some stocks have mismatches between NSE symbol and Yahoo Finance ticker. A manual override dict handles these:

"TRIL" → "TARIL.NS" "INDEGENE" → "INDGN.NS" "PRICOL" → "PRICOLLTD.NS" "EMS" → "EMSLIMITED.NS" "KPGEL" → "KPGEL.BO"
📁 Stock Metadata Format (Stocks List.json)

Each entry in Stocks List.json follows this schema:

{ "ticker": "ZOMATO", "name": "Zomato Ltd", "sector": "Consumer Goods & Retail", "exchange": "NSE" }

The exchange field determines the suffix: NSE → .NS BSE → .BO

Index Math Engine
Equal-weighted index synthesis with Base 1000 normalization
📌 The Core Formula

Every stock's price history is normalized to a base of 1000 on the first day it appears. This removes price bias — a ₹5 stock and a ₹5000 stock contribute equally.

Normalized Price(t) = (Raw Close(t) / Raw Close(Day 0)) × 1000

The Index Value on any day is the arithmetic mean of all normalized prices in that sector:

Index(t) = Σ [Normalized_i(t)] / N   (where N = number of stocks)

Since all stocks start at 1000 on Day 0, the index also starts at 1000 — exactly like how Nifty started at 1000 on November 3, 1995.

🕯️ Synthesized OHLC Candlesticks

Each day's candle is synthesized:
• Open = mean of all stocks' open
• High = mean of all stocks' high
• Low = mean of all stocks' low
• Close = mean of all stocks' close

This gives the chart a realistic look with wicks and bodies, just like a real index candle.

📆 Multi-Timeframe Returns

6 return windows computed per stock & index:
1D 1 trading day back
1W 5 trading days back
1M 21 trading days back
3M 63 trading days back
6M 126 trading days back
1Y full year (first record)

🏭 Sector Qualification Rule

A sector only gets its own sub-index if it has 4 or more stocks. Smaller sectors are included in the Master Index but don't get a standalone chart.

Result: 1 Master Index + 13 Sector Sub-Indices = 14 total indices across all 132 stocks.

Heatmap Engine
Finviz-style squarified treemap built with D3-hierarchy
🗺️ Treemap Layout Algorithm

The heatmap uses D3's treemap() with the squarify tiling algorithm — the same technique used by Finviz and Bloomberg. It recursively subdivides a rectangle into child rectangles with aspect ratios as close to 1:1 as possible.

Tile size = absolute value of % return for the selected timeframe. Bigger movers = bigger tiles.
Tile color = diverging red–green scale:

≤ −5%
−3%
−1%
~0%
+1%
+3%
≥ +5%
📐 Data Structure (heatmap_data.json)

Follows D3's hierarchical format:

{ "name": "Market", "children": [ { "name": "IT & Tech Services", "children": [ { "name": "INFY", "returns": { "1d": 1.2, "1w": 3.4 }, "value": 1 } ] } ] }
⚡ Interactive Features

• Timeframe toggle — switch 1D/1W/1M/3M/6M/1Y without re-fetching
• Hover tooltips — company name + % return
• Sector grouping — tiles grouped visually with labels
• Responsive canvas — resizes via ResizeObserver

Execute build_indices.py

Frontend Dashboard
The ultra-premium dark-themed HTML/JS dashboard
🏗️ Architecture

The entire frontend is a single HTML file (index.html, ~68KB) with embedded CSS and JavaScript. No build step, no bundler, no framework. On page load, the JS fetches all required JSON files in parallel using Promise.all(), then renders each component.

📈 Chart View

Powered by TradingView Lightweight Charts v5. Renders candlestick + volume. Toggle between Candle mode and Line mode. Fully interactive zoom, scroll, crosshair.

🟩 Heatmap View

Rendered on a Canvas element via D3-hierarchy. Includes 6-timeframe toggle and hover tooltips.

📋 Table View

Sortable, searchable table of all 132 stocks showing multi-timeframe performance. Live search filters on every keystroke.

⚡ Lightweight Charts v5 — Breaking API Change

TradingView made a breaking change in v5. Old API (throws errors in v5):

chart.addCandlestickSeries({ ... }) // DEPRECATED in v5

Correct v5 API used in this project:

chart.addSeries(LightweightCharts.CandlestickSeries, { ... }) // v5

Our implementation wraps both in a compatibility layer that detects which API is available.

How to Run Locally
Get the pipeline running on your machine in minutes
Step 1 — Install Python Dependencies
# Create a virtual environment (recommended) python3 -m venv .venv source .venv/bin/activate # Install required packages pip install yfinance pandas requests
Step 2 — Run the Data Pipeline
# First run: fetches ~1 year of history for all 132 stocks # Takes 5-15 mins due to rate limiting (1.5-3s per stock) python build_indices.py # Subsequent runs are fast — delta only (new days only) ~1-2 minutes
Step 3 — Serve the Dashboard
# Use Python's built-in HTTP server (avoids CORS issues with local JSON) python3 -m http.server 8080 # Open in your browser open http://localhost:8080
Why a local server? The dashboard fetches JSON via fetch() which requires HTTP. Opening index.html directly as a file:// URL triggers CORS errors and charts won't load.
